# Przeglądarka naborów BFIG

Strona: **https://robkub71.github.io/bfig-dotacje-web/**

Wyszukiwarka i przeglądarka naborów dotacyjnych monitorowanych przez Bieruńską Fundację
Inicjatyw Gospodarczych — nabory krajowe, wojewódzkie (śląskie), powiatowe i gminne
istotne dla powiatu bieruńsko-lędzińskiego.

## ⚠️ Repozytorium generowane automatycznie

`index.html` jest **wytwarzany maszynowo** z systemu monitoringu i nadpisywany przy każdej
aktualizacji (poniedziałek / środa / piątek). **Ręczne zmiany zostaną utracone.**
Kod źródłowy, konfiguracja źródeł i logika systemu znajdują się w osobnym, prywatnym repozytorium.

## Zastrzeżenie

Dane pochodzą z publicznych ogłoszeń instytucji finansujących i mają charakter **informacyjny**.
Wiążąca jest wyłącznie treść ogłoszenia u organizatora naboru — zawsze zweryfikuj termin,
kwotę i warunki pod linkiem źródłowym przed podjęciem decyzji.
